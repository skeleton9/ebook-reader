# 页间 · EPUB 阅读与 AI 共读

本地优先的中文电子书阅读工作台。支持 EPUB 2/3 导入、书架、章节跳转、阅读进度恢复、划线收藏、评论，以及按章节存储的 AI 总结与对话。

## 运行

需要 Node.js 22.12+。

```powershell
npm install
npm run dev
```

首次运行时复制 `.env.example` 为 `.env`，填写下文的 AI 与语音配置。开发页面默认 http://127.0.0.1:5173 ，前端代理 `/api` 到 `DEV_API_PORT` 指定的本地端口（默认 3001）。

```powershell
npm test
npm run build
npm start
```

构建后 `npm start` 在 `PORT` 指定的端口同时提供页面和 AI 接口（示例默认 5173）。启动生产模式前请停止占用该端口的开发服务。浏览器阅读记录按站点地址保存，更改端口会使用独立的书库。

## 配置 AI

在页面右上角的设置中填写 OpenAI 兼容接口的基础地址、模型、API Key；页面填写的密钥仅存在内存中，刷新即清除。地址和模型会保存在本地。

所有服务端配置集中在项目根目录 `.env`，不再依赖其他项目的配置文件。服务固定加载本项目的文件，修改后重启；系统环境变量可覆盖同名设置。密钥不会返回前端，也不会写入书籍数据库。自定义接口必须支持 `/chat/completions` 和 SSE 流，可使用 HTTPS 接口或本机 HTTP 接口。

| 配置项 | 用途 |
| --- | --- |
| `PORT` | 生产服务端口（`npm start`） |
| `DEV_API_PORT` | 开发 API 端口及 Vite 代理目标 |
| `AI_BASE_URL` | 文本模型基础地址，例如方舟的 `https://ark.cn-beijing.volces.com/api/v3` |
| `AI_MODEL` / `AI_API_KEY` | 文本模型名称与密钥 |
| `DOUBAO_TTS_API_KEY` | 豆包语音密钥 |
| `DOUBAO_TTS_URL` / `DOUBAO_TTS_RESOURCE_ID` | 流式合成接口地址与资源 ID |
| `DOUBAO_TTS_FEMALE_VOICE` / `DOUBAO_TTS_MALE_VOICE` | 女声与男声音色 ID |

点击总结或发送问题时，会发送当前章节（最长前 60,000 字符）、选文（最长 12,000 字符）和最近 20 条对话到配置的服务商。超长章节会在 AI 系统提示中声明范围限制。费用由所配置的服务账号承担。

## 使用

- 导入 `.epub` 文件，解析章节、目录、元信息和内嵌位图；以文件 SHA-256 防止重复导入。
- 正文中选择文字后，使用底部工具条划线、写评论、围绕选文提问。点击划线可编辑批注；左侧批注列表可跳转原文。
- AI 总结以章节为单位保留多个版本；对话保留历史和选文上下文。两者支持复制与 Markdown 导出。
- Markdown 支持 GFM 表格、列表、代码块；Mermaid 在生成完成后渲染，生成时保留源码，非法语法回退显示源码。
- 书架可导出原 EPUB；删除书籍会一并删除其批注、总结和对话，删除前确认。
- 自动保存阅读位置，支持字体、字号、背景配色与自定义背景颜色，偏好自动保存。
- 顶部采用紧凑布局，左侧封面与书名并排，过长导航标题截断；右侧 AI 栏可拖动调整宽度并记忆，双击边界恢复默认。
- 支持深色模式及窄屏目录与 AI 抽屉，阅读偏好可点击外部或按 Esc 关闭。

## 豆包流式语音朗读

在本地 `.env` 设置 `DOUBAO_TTS_API_KEY`（豆包语音控制台的 API Key，与方舟文本模型密钥独立），重启服务后可使用正文顶部的扬声器、总结与对话下方的“朗读”以及选文工具条。音色可在阅读偏好中选择 Vivi 2.0 女声或云舟 2.0 男声。

采用豆包 TTS 2.0 HTTP 单向流式合成，后端保管密钥、前端接收 PCM 音频立即播放。支持暂停、继续、停止与语速调整，切换书籍或章节时停止朗读。长内容自动分段连续播放；过滤 Markdown 标记、代码块和 Mermaid 源码。浏览器需要支持 Web Audio API；所选文本会发送至豆包语音服务并使用对应账号额度。语音不会自动保存在书库中。

正文朗读时以薄荷绿色高亮当前句，收藏划线仍保留黄色。高亮由音频播放时间驱动；浏览器支持时使用 CSS Custom Highlight，其他浏览器回退为段落高亮。句子离开可视区时跟随滚动，手动滚动会关闭跟随，可在播放器重新开启。

播放器支持上一句、下一句及按句定位的进度条：拖动时预览目标文字，松开后跳转并重新缓冲。暂停时跳转保持暂停；键盘方向键、Home / End 也可操作进度。选中正文后点击“从这里读”，从所在句一直读到本章末尾。跳转会取消旧请求和旧音频，沿用本次朗读音色和当前语速。

播放器位于顶部空白区域，主栏仅保留上一句、播放/暂停、下一句、进度和关闭。语速、音色、跟随开关、重读当前句及停止放在“更多”面板，点击外部或按 Esc 收起。窄屏下控制条排列在顶栏第二行，不覆盖正文。

切换男声或女声会立即取消旧音频与请求，从当前句使用新音色继续；暂停状态下切换仍保持暂停，点击继续后使用新音色。阅读偏好和播放条中的音色选择保持同步。

右上角“AI 与语音设置”可调整语音接口 URL、语音模型（资源 ID）、女声音色 ID 和男声音色 ID。首次默认读取服务端 `.env`，保存后在当前浏览器持久化并覆盖服务端默认；保存时会从当前句应用新配置，保持暂停状态。音色选择仍显示“女声”“男声”，语音密钥始终由服务端保管。接口填写豆包 HTTP 单向流式完整地址；允许 HTTPS 或本机 HTTP，仅向与服务端默认地址相同的 origin 转发密钥，更换域名或端口需同步修改 `.env` 中的 URL 和密钥并重启。

参考：[官方流式接口](https://docs.volcengine.com/docs/doubao-voice/unidirectional-streaming-text-to-speech-http?lang=zh)、[官方音色表](https://docs.volcengine.com/docs/doubao-voice/tone-list-3?lang=zh)。

## 数据存储与边界

书籍原文件、处理后的正文、批注、进度和 AI 历史存于当前浏览器、当前站点 origin 的 IndexedDB；字体、外部 AI 请求需要网络。清理站点数据、切换浏览器或更换端口不会自动迁移记录。建议导出原书和重要 AI 记录。

当前实现是个人单机版，没有账户和跨设备同步。导入限制 80 MB，解压正文限制 1500 万字符，位图资源限制 50 MB。DRM 加密、音视频、脚本、原书复杂 CSS、SVG 图片与固定版式不在支持范围内；正文按统一排版展示。导入 HTML 经过 DOMPurify 清洗，禁用远程资源和书内可执行内容；AI Markdown 不执行原始 HTML，Mermaid 使用 strict 模式。

## 实施规划与结构

1. **阅读基础（已实施）**：EPUB 清单/spine/导航解析、图片嵌入、本地书架、进度恢复。
2. **思考与批注（已实施）**：文本偏移锚点、划线、评论、批注跳转与编辑。
3. **AI 共读（已实施）**：服务端代理、SSE 流、取消/错误恢复、总结版本、选文与章节对话、Markdown/Mermaid。
4. **交付验证（已实施）**：解析和流协议测试、类型检查、生产构建、界面检查。
5. **后续可选**：完整书库备份恢复、全文检索、超长章节分段总结、同步和账户体系。

`src/epub.ts` 处理导入；`src/db.ts` 封装持久化；`src/stream.ts` 处理流；`src/Markdown.tsx` 处理 AI 内容排版；`src/App.tsx` 组织交互；`server/index.mjs` 提供本机 AI 转发与静态托管。

本地 `.env` 不纳入 Git；`.env.example` 提供全部配置项与空密钥模板，新环境需单独填写密钥。
